# ExternalOfficeManager Configuration

`ExternalOfficeManager` is named [AttachedOfficeManager](attached-manager.md) since JODConverter 5.0: it attaches to
office processes that JODConverter does not start, on the same machine or on another one. The old class and the
`jodconverter.external.*` properties of the Spring Boot starter still work, deprecated. See the
[migration guide](../migration-guides/migration-guide-5.0.0.md#attached-office-manager).
